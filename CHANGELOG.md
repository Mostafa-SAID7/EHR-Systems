## [1.0.0] — 2026-07

### Added
- Angular 18 frontend with standalone components and Signals state management
- ASP.NET Core 8 microservices backend (Clean Architecture + CQRS)
- Patient management: demographics, medical history, search
- Appointment scheduling with calendar integration
- Medical records: SOAP notes, ICD-10 diagnoses, CPT procedures
- Prescription management and eRx support
- Lab & imaging results with PDF viewer
- Billing & insurance claims workflow
- JWT authentication with RBAC (Doctor, Nurse, Receptionist, Admin)
- HIPAA-compliant immutable audit logging
- SignalR real-time updates for live patient data
- Docker & Kubernetes deployment manifests
- GitHub Actions CI/CD pipelines
- i18n support (English + Arabic RTL)
- WCAG AA accessibility compliance
- PWA support with service workers
- Full documentation suite in `docs/`
